Typed circuit diagrams, interactive node labels, and portable SVG. One JSON document shared by the editor, React components, and CLI. No account or backend. Not a simulator.

## Quick start

```sh
git clone https://github.com/crafter-lab/circuitkit.git
cd circuitkit
bun install --frozen-lockfile
bun run dev
```

Open http://localhost:3000. Explore the editor, gallery, and annotated lessons.

Not published to npm yet. See the [guide](docs/guide.md) for CLI, React, and local-package usage, or [testing](docs/testing.md) to contribute.
